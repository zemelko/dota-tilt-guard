# Dota Tilt Guard

Небольшое приложение для macOS, которое помогает остановиться перед отправкой ругательств в Dota 2. Раньше называлось Calm Chat. Интерфейс переключается между русским и английским; выбор сохраняется.

[Скачать DMG](https://github.com/zemelko/calm-chat/releases/latest) · [English / документация разработчика](README.md)

## Установка

1. Открой DMG и перетащи **Dota Tilt Guard.app** в **Applications / Программы**.
2. Заверши старую версию, извлеки образ диска и запусти приложение из Программ.
3. Для текстового фильтра разреши приложение в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ / Accessibility**. Включи защиту, вернись в Dota, нажми Esc, затем открывай чат обычным Enter.
4. Для голоса нажми шестерёнку **«Установка компонентов»**. Установи BlackHole **2ch** по официальной ссылке и перезагрузи Mac. Если выбранный язык ещё не установлен, нажми **«Загрузить язык через macOS»**.
5. На вкладке голоса выбери настоящий микрофон и тот же язык. Разреши доступ к микрофону и включи голосовую защиту. В Dota выбери системный микрофон или BlackHole 2ch.

Сборка предназначена для **Apple Silicon**. Текстовый фильтр требует **macOS 13+**, голос — **macOS 26+**. Dota 2 устанавливается отдельно через Steam. Python, Homebrew, ключи API и отдельные нейросетевые программы не нужны.

В DMG лежат приложение, инструкция и ссылки на компоненты. BlackHole и языковые данные Apple не вложены: они устанавливаются отдельно. Для первоначальной настройки голоса нужен интернет. После неё фильтрация и распознавание работают локально, аудио и переписка не отправляются в сеть и не сохраняются.

Это тестовая сборка без нотариального заверения Apple. При блокировке загруженного приложения macOS можно разрешить запуск именно этой копии через **Конфиденциальность и безопасность → Всё равно открыть**, если ты доверяешь источнику. У версии 0.5.0 новый идентификатор: выдай доступ приложению Dota Tilt Guard из Программ, а прежние записи Calm Chat удали. При следующих обновлениях также может потребоваться добавить приложение в Accessibility заново.

## Ограничения MVP

Текст проверяется по русскому и английскому словарю. Поддерживаются обычный набор, Backspace и выделение всего через Command+A / Control+A с удалением или заменой. Пустой чат закрывается Enter. После вставки, перемещения стрелками, частичного выделения, щелчка мышью или смены окна нажми Esc и начни сообщение заново. Чат до игры, в который нужно нажать мышью, не поддерживается.

В голосе обнаруженное ругательство отключает передачу на три секунды. Новое срабатывание продлевает паузу, распознавание продолжает слушать. Первое слово может проскочить. Интонация не анализируется; словарь может ошибаться и не ловит все оскорбления.

Голосовой фильтр действует на программы, использующие системный вход. Другой явно выбранный микрофон обходит фильтр. При обычном выключении защиты возвращается прежний системный микрофон; после аварийного завершения выбери его вручную в настройках звука, если остался BlackHole.

Проект независимый и не одобрен Valve. Dota 2 принадлежит Valve. Программа не меняет файлы и память игры; гарантий совместимости с античитом нет.
